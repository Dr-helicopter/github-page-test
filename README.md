# 🐦 GitHub Page Test: Flappy Bird

A tiny Flappy Bird clone made in Godot.

## Why does this exist?

I was bored.

I wanted to test out **GitHub Pages** and see what the deployment process is like.

## Play it

The game is playable directly in your browser:

https://dr-helicopter.github.io/github-page-test/

No installation required.

## About the project

* Engine: Godot
* Export target: Web (HTML5/WebAssembly)
* Purpose: Testing GitHub Pages deployment
* Development time: ~1 hour

This was not intended to be a serious game project. It was made as a quick experiment to verify that Godot web exports could be hosted easily through GitHub Pages.
